# 4.5 — Commissioning and redline discipline

## Learning objectives

- Run I/O checkout with a written sheet
- Manage forces during checkout ethically
- Execute functional tests by mode
- Leave as-built documentation others trust

**Time:** 5–6 h | **Prereq:** P3  
**Lab:** `../../LABS/04-expert/LAB-4.5-io-checkout.md`  
**Template:** `../../RESOURCES/templates/io-checkout-sheet.md`

---

## Electrician map

Commissioning is **ring-out + functional test**, but the “prints” include ACD, HMI, and network.

---

## Order that saves pain

1. Power & network  
2. I/O point-to-point  
3. Permissives & safety boundary checks  
4. Manual mode devices  
5. Auto sequences  
6. Fault insertion tests  
7. Performance / scan notes  
8. As-built freeze
