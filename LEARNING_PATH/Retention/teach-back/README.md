# Phase teach-back exercises

**Rule:** If you cannot teach it, you do not own it yet.

After each major phase (and before starting the next), complete that phase’s teach-back **out loud** (preferred) or written. Record date in `../progress-log.md`.

| Phase | File | Gate project |
|-------|------|--------------|
| 1 Foundation | [TB-phase1.md](TB-phase1.md) | P1 |
| 2 Intermediate | [TB-phase2.md](TB-phase2.md) | P2 |
| 3 Advanced | [TB-phase3.md](TB-phase3.md) | P3 |
| 4 Expert | [TB-phase4.md](TB-phase4.md) | P4 + Capstone |

## Format

1. **Audience:** brand-new industrial electrician apprentice  
2. **Time box:** 10–20 minutes spoken  
3. **Props allowed:** blank whiteboard / paper only (no reading the manual)  
4. **Challenge questions:** answer without notes  
5. **Self-score:** 1–5 on clarity, accuracy, safety  

Pass: average ≥ 4 and no safety-critical errors.
