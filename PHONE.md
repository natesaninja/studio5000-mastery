# Phone guide

This site is built for **phones and tablets** (GitHub Pages + Docsify).

## Use at work (recommended)

1. Open the site URL on your phone.  
2. Tap **Add to Home Screen** (Safari Share → Add to Home Screen / Chrome menu → Install).  
3. Tap **🚨 Job aid** in the top bar.  
4. Use the **menu button** (bottom-left circle) for the full sidebar.  
5. Use **Search** for: `won’t start`, `force`, `TON`, `major fault`, etc.

## Offline-ish

After the first visit, a simple service worker caches core pages for weak plant Wi‑Fi.  
Still open critical trees once while online so they cache.

## Tips

| Gesture / UI | Action |
|--------------|--------|
| Bottom-left blue button | Open/close sidebar |
| Top **Job aid** | Floor reference |
| Top **Learn** | Study path |
| Search box | Find any page text |
| Swipe tables sideways | Wide tables don’t break layout |
| Pinch on images | Zoom (if any) |

## Don’t

- Don’t download to a production PLC from a phone browser — use the laptop + Studio 5000.  
- This is a **reference**, not a programming terminal.

## Desktop GitHub

Raw markdown also works on github.com if the Pages site is down — clone or browse the repo folders `ON_THE_JOB/` and `LEARNING_PATH/`.
