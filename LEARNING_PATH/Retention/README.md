# Retention systems

Finishing modules is not mastery. **Forgetting is the default** unless you schedule retrieval.

This folder is the long-term memory engine for Studio 5000 Mastery.

## How retention works in this path

```
Learn module → Lab → Quiz → Teach-back (module)
     ↓
Spaced flashcards (1 day → 1 week → 1 month)
     ↓
Mini-project / major project reuses old skills
     ↓
Phase teach-back gate
     ↓
Capstone (design + build + break/fix)
```

### Rules

1. **Closed notes** on flashcard sessions.  
2. **Speak answers aloud** (forces real recall).  
3. Missed card → restudy the linked module **same day**, not “later.”  
4. Phase teach-back is a **gate**, not optional writing homework.  
5. Projects must **reuse** prior tags/patterns (no greenfield every time).

## Quick start (today)

1. Open [SCHEDULE.md](SCHEDULE.md) and mark your start date.  
2. After each study day: 15–30 min flashcards due.  
3. After each phase: complete that phase’s teach-back in `teach-back/`.  
4. Track projects in [`../../PROJECTS/README.md`](../../../PROJECTS/README.md).  
5. Expert bar: [expert-checklist.md](expert-checklist.md) — aim to check items only with evidence.
