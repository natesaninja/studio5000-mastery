# Teach-back — Phase 4 Expert / Capstone

**Time box:** 20–30 min  
**Prerequisite:** P4 + Capstone complete (or Capstone in final review)

---

## Part A — Explain (15 min)

1. Standard logic vs **safety** responsibilities (what you will never bypass).  
2. Task performance: continuous vs periodic; what overlap means on a fast sensor.  
3. Multi-controller **interface contract** (heartbeat, defaults, single owner of each motor).  
4. Controller **recovery** runbook (dead CPU → production).  
5. Commissioning: I/O checkout order and force log.  
6. 15-minute field triage script for ops.  
7. Capstone story: design choices, one fault you found, RCA.

## Part B — Challenge (closed notes)

1. Two controllers both start the same conveyor — hazard?  
2. Ops demands force on light curtain — your words?  
3. Major fault reappears immediately after clear — meaning?  
4. List your recovery kit (4+ items).  
5. First screen on a “haunted” machine that ignores Stop?

## Part C — Presentation

10-minute “handoff to the next electrician” on your capstone machine:
- How it runs  
- How it faults  
- How to troubleshoot  
- What’s still fragile
