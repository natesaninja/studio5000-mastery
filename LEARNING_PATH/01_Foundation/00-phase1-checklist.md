# Phase 1 master checklist

## Before you start
- [ ] Studio 5000 available (Emulate or hardware)  
- [ ] Read `docs/00-how-to-use-this-path.md`  
- [ ] Lab report template ready  

## Modules
- [ ] 1.1 PLC vs hardwired — lab, quiz ≥80%, teach-back, +1 day review  
- [ ] 1.2 Hardware — lab, quiz, teach-back  
- [ ] 1.3 Project structure — skeleton ACD  
- [ ] 1.4 Tags — full INF01 set  
- [ ] 1.5 Digital I/O — aliases + I/O map + wrong-alias RCA  
- [ ] 1.6 Ladder — 1.6A, 1.6B, 1.6C  
- [ ] 1.7 Online/force — empty force table signed  
- [ ] 1.8 Fault kit — 5 RCAs  

## Gate
- [ ] Cumulative quiz ≥ 85%  
- [ ] P1 rubric ≥ 85  
- [ ] SR-1 scheduled (+1 day / week / month)  

## Artifacts to keep
- [ ] `PKG_CELL01` ACD (local)  
- [ ] I/O map  
- [ ] Test plans  
- [ ] Teach-backs  

## Do not advance to Phase 2 until
You can build start/stop + permissives from a schematic **without notes**, alias I/O correctly, remove forces, and separate field vs program faults with a tree.
