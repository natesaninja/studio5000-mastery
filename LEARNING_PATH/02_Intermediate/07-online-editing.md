# 2.7 — Online editing and change discipline

## Learning objectives

- Perform pending online edits and finalize correctly
- Know classes of changes that require download / offline
- Document changes (who/why/when)
- Refuse unsafe online edits

**Time:** 4–5 h | **Prereq:** 2.6, 1.7  
**Lab:** `../../LABS/02-intermediate/LAB-2.7-online-permissive.md`

---

## Electrician map

Online edit ≈ **hot work on a live control panel**: possible, valuable, and easy to do wrong.

---

## Discipline checklist

1. Authorization  
2. Backup / known ACD revision  
3. Smallest change that solves the issue  
4. Test plan  
5. Pending → test → accept/finalize per software workflow  
6. Redline + save ACD + note in shift log  
7. No leftover test rungs  

---

## When to say no

- You don’t understand side effects  
- Safety-related standard logic “bypass”  
- Major structural changes better done offline during window  
- You’re being pressured to skip verification
