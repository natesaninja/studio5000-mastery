# 2.6 — Trending

## Learning objectives

- Create trends for digital and analog tags
- Choose sample rate vs capture goal
- Prove intermittents with artifacts (screenshot/export)
- Use trends in handoff notes to the next shift

**Time:** 3–4 h | **Prereq:** 2.5  
**Lab:** `../../LABS/02-intermediate/LAB-2.6-intermittent-trend.md`

---

## Electrician map

**Trend ≈ chart recorder / portable scope** for tags.

---

## Practice rules

- Name trends after the problem, not “Trend1”  
- Include cause + effect tags (e.g., photoeye + motor run + fault)  
- For intermittents: longer capture, not just staring at rung green  
- Save evidence in the project folder or CMMS note
