# 4.4 — Firmware, SD card, disaster recovery

## Learning objectives

- Match firmware and project expectations
- Use SD store/load concepts where supported
- Build a recovery kit checklist
- Practice upload/download discipline after failure

**Time:** 4–5 h | **Prereq:** 1.7  
**Lab:** `../../LABS/04-expert/LAB-4.4-recovery-runbook.md`

---

## Electrician map

Known-good ACD + firmware notes + SD image ≈ **latest marked-up prints and a spare tested brain**.

---

## Recovery kit (minimum)

- [ ] Latest as-built ACD  
- [ ] Firmware version recorded  
- [ ] IP / node / path notes  
- [ ] I/O list  
- [ ] Passwords / roles procedure (site)  
- [ ] Who to call (OEM/controls eng)  

---

> “Walk through replacing a dead controller from toolbag to production.”
