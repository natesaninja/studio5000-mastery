# Spaced review schedule

## Intervals (use these)

| Review # | When after first learn | Goal |
|----------|------------------------|------|
| R0 | Same day | Encode (quiz + teach-back) |
| R1 | **+1 day** | Stop overnight forgetting |
| R2 | **+3 days** | Strengthen |
| R3 | **+1 week** | Medium-term |
| R4 | **+1 month** | Long-term |
| R∞ | **Monthly** forever | Plant-floor readiness |

If you miss a window: do it late **once**, then continue — don’t restart the whole course.

## Session recipe (20–30 minutes)

1. **Due cards only** (or max 40 cards if backlog)  
2. Grade: Again / Hard / Good  
3. Again → write one sentence why you missed it  
4. If Again on fault tree → open that DT file and walk one example  
5. Log date in `progress-log.md`

## Anti-patterns

| Don’t | Do instead |
|-------|------------|
| Only re-read notes | Closed-note flashcards |
| Skip reviews to “finish faster” | Protect 20 min/day |
| Review only what you like | Bias to **missed** and fault cards |
| Never teach | Phase teach-backs |
