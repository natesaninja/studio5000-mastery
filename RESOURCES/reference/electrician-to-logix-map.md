# Electrician → Logix quick map

| Electrician concept | Logix / Studio 5000 |
|---------------------|---------------------|
| NO contact | XIC |
| NC contact | XIO |
| Coil | OTE |
| Latching relay | OTL / OTU |
| Holding contact | Seal-in branch |
| On-delay timer | TON |
| Off-delay timer | TOF |
| Retentive timer | RTO |
| Counter | CTU / CTD + RES |
| Master control relay zone | MCR (use carefully) |
| Drawing sheet | Routine |
| Equipment section | Program |
| How often logic re-evaluates | Task (continuous/periodic) |
| Terminal label | Tag |
| Jumper wire name to terminal | Alias tag |
| Wire to another panel (live) | Produced/Consumed |
| Call other panel for data | MSG |
| Chart recorder | Trend |
| Jumper on contact | Force |
| Hot work on live panel | Online edit |
| Marked-up prints | As-built ACD + redlines |
| Dual-channel e-stop / safety relay | Safety I/O + safety task (not standard BOOL theater) |
| VFD run/ref/fault | Typically networked or digital + analog tags |
| Photoeye / prox | Digital input tag |
| 4–20 mA transmitter | Analog input + scale to EU |
| OL contact in series | Permissive BOOL in series logic |
| HOA switch | Mode tags + selector logic |
| Drum sequence / SOO | SFC or ST state machine |
| Typical circuit repeated | AOI + UDT |
| Panel layout of cards | I/O Configuration |
| Slot / landing | Module path + bit |
| Megger/meter first | Still valid — then online tools |
